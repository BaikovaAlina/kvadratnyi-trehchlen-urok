# Квадратный трёхчлен — интерактивный урок

Учебная презентация-тренажёр по алгебре. Открывается в браузере, работает без интернета и без установки: весь урок — один файл `index.html`.

**Открыть урок:** https://baikovaalina.github.io/kvadratnyi-trehchlen-urok/

## Что внутри

| Блок | Тема | Что делает ученик | Заданий |
|---|---|---|---|
| 1 | График по точкам | Заполняет таблицу значений, отмечает точки на координатной плоскости, проводит параболу | 5 + тренажёр |
| 2 | Знаки *a* и *c* по графику | По рисунку параболы определяет знаки старшего коэффициента и свободного члена | 8 + тренажёр |
| 3 | Коэффициенты и дискриминант | Выписывает *a*, *b*, *c* из записи функции и вычисляет *D = b² − 4ac* | 8 + тренажёр |
| 4 | Корни по формуле | Находит дискриминант, число корней и сами корни | 8 + тренажёр |

Перед каждым блоком — слайд с теорией и разобранным примером. В конце каждого блока — тренажёр со случайными заданиями, которые не заканчиваются. Последний слайд показывает итоги по блокам.

## Как пользоваться

- Листать: кнопки «Назад» / «Далее» внизу или клавиши ← →.
- Разделы — вкладки вверху, задания внутри блока — кружки внизу.
- Ответы проверяются сразу; при ошибке появляется подсказка, а не готовый ответ.
- «Показать решение» открывает полный разбор (такое задание в зачёт не идёт).
- Дроби можно вводить как `0,5` или `1/2`, минус — обычным дефисом.
- Результаты хранятся в браузере ученика и сбрасываются кнопкой на слайде «Итоги».
- На любой слайд можно дать прямую ссылку, например `…/#b3-1` — блок 3, задание 1.

Подходит для проектора, ноутбука и телефона.
